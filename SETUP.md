# SETUP — GitHub Profile README Configuration Guide

A concise checklist of every step required to make this profile README fully functional.

---

## 1. Repository Setup

Your GitHub profile README must live in a **special repository** whose name exactly matches your GitHub username.

| Step | Action |
|------|--------|
| 1 | Go to [github.com/new](https://github.com/new) |
| 2 | Set the repository name to exactly: `deepaksureshnaik2006-commits` |
| 3 | Set visibility to **Public** |
| 4 | Do **not** initialise with a README (you will push yours) |
| 5 | Push the contents of this folder to the `main` branch of that repository |

```bash
# From inside this project folder:
git init
git add .
git commit -m "feat: add premium GitHub profile README"
git branch -M main
git remote add origin https://github.com/deepaksureshnaik2006-commits/deepaksureshnaik2006-commits.git
git push -u origin main
```

## 3. Contribution Snake Animation Setup

The snake animation is generated by a GitHub Actions workflow (`.github/workflows/snake.yml`).

**Steps:**

1. Push this repository to GitHub (Step 1 above).
2. Go to your repository → **Settings** → **Actions** → **General**.
3. Under *Workflow permissions*, select **Read and write permissions** → Save.
4. Go to **Actions** → **Generate Contribution Snake** → **Run workflow**.
5. Wait for the workflow to complete (roughly 1–2 minutes).
6. The SVGs will be pushed to a new `output` branch automatically.
7. The snake animation in your README will then display correctly.

> **Note:** The snake image will show a broken link until the workflow runs at least once successfully. After the first run, it updates automatically every day at midnight UTC.

## 4. Previewing the README Locally

You can preview the rendered Markdown before publishing using any of these methods:

- **VS Code** — Install the [Markdown Preview Enhanced](https://marketplace.visualstudio.com/items?itemName=shd101wyy.markdown-preview-enhanced) extension and open the preview panel.
- **GitHub web editor** — Upload the file to a private repository and use the Preview tab.
- **grip** (Python tool) — Renders GitHub-flavoured Markdown locally:
  ```bash
  pip install grip
  grip README.md
  # Open http://localhost:6419 in your browser
  ```

> Note: External widgets (stats, streak, activity graph, snake) only render correctly when hosted on GitHub, not in local previews.

## 6. Privacy Reminder

- **Do not upload your resume PDF** to this repository.
- **Do not commit API keys**, tokens, or `.env` files.
- The `.github/workflows/snake.yml` file uses only `GITHUB_TOKEN`, which is automatically provided by GitHub Actions and requires no manual secrets configuration.
- Review the README before publishing to confirm no personal information you wish to keep private is exposed.
