## 🚀 Featured Projects

<details>
<summary><b>🎬 &nbsp;VIDARA AI — AI Video &amp; Podcast Intelligence Platform</b></summary>

<br/>

> An AI-powered platform designed to analyse long-form video and podcast content, enabling intelligent clip generation, speaker identification, semantic search, and long-content question answering.

**Problem:** Consuming long-form video and podcast content is time-consuming. There is no easy way to extract meaningful moments, search within content semantically, or quickly access specific speaker segments without watching the full recording.

**Approach & Key Features:**

- Transcribes long-form audio/video with high accuracy using **Whisper Large-v3**
- Applies **speaker diarization** to identify and separate individual speakers within recordings
- Generates context-aware **video clips** at meaningful moments using FFmpeg media processing
- Implements **conversation-aware semantic search** for content-level question answering over transcripts
- Produces **AI-generated summaries** and **audience-specific notes** via Groq API (LLaMA)
- Preserves narrative context with **synchronised subtitles** and conversation-aware clip selection

| Category | Details |
|---|---|
| **Stack** | Python · FastAPI · Whisper Large-v3 · Groq API · FFmpeg · Supabase |
| **Scale** | Not documented |
| **Performance** | Not measured |
| **Security** | Not documented |
| **Impact** | 🏆 **1st Place — HACKERRING 2.0** (36-hour national hackathon) with Team Knight Coders |
| **Repository** | [SHREYAS-J-S-23/HackRing_knight_coders](https://github.com/SHREYAS-J-S-23/HackRing_knight_coders) |

**Engineering Highlights:**

The platform connects a speech AI pipeline (Whisper transcription + diarization) with an LLM semantic layer (Groq API), coordinated through a FastAPI backend. FFmpeg handles media clip extraction, and Supabase provides persistent storage for transcripts and user sessions. The system bridges multimodal content understanding with a structured semantic retrieval interface capable of answering questions over hours-long content.

<summary><b>🔍 &nbsp;QueryAI — AI-Powered SQL Query Optimiser</b></summary>

<br/>

> A full-stack web application that uses an LLM to analyse submitted SQL queries, identify performance bottlenecks, suggest missing indexes, and deliver actionable optimisation recommendations.

**Problem:** Developers and data engineers often write inefficient SQL queries without immediate, structured feedback on performance issues, missing indexes, or query structure problems.

**Approach & Key Features:**

- Accepts user-submitted SQL queries via a responsive **React + Vite** frontend
- Routes queries to a **Node.js / Express** backend for LLM-backed analysis
- Integrates the **Groq API** with an LLM to generate detailed performance analysis, issue detection, and optimisation suggestions
- Stores user authentication and query history persistently in **Supabase** with secure user sessions
- Displays AI-generated insights, index suggestions, and rewritten queries in a clean dashboard interface

|---|---|
| **Stack** | React · Vite · Node.js · Express.js · Supabase · Groq API |
| **Scale** | Not documented |

| **Security** | Supabase authentication; JWT-managed user sessions |
| **Impact** | Demonstrates practical LLM integration for developer tooling; Live Demo available |
| **Repository** | [deepaksureshnaik2006-commits/queryai](https://github.com/deepaksureshnaik2006-commits/queryai) |

**Engineering Highlights:**

QueryAI demonstrates a clean full-stack AI integration pattern: a typed React frontend manages submission and results display, the Express backend orchestrates LLM API requests, and Supabase handles persistent user data. The Groq API integration enables fast, structured LLM responses suited to real-time SQL diagnostics.
